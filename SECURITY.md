# Security and safety reporting

This project controls ventilation equipment. Please report issues that could expose credentials, allow unauthorised control or firmware updates, or cause unexpected relay operation privately when possible.

Use GitHub's **Report a vulnerability** feature for this repository once private vulnerability reporting is enabled. If that option is unavailable, open a public issue asking the maintainer for a private contact method. Do not include exploit details, credentials, private network addresses, or personal data in that issue.

Include the affected PCB revision, firmware version, device model, expected behaviour, observed behaviour, and safe reproduction steps. Do not test a suspected issue on a connected ventilation installation if it could change airflow or heating unexpectedly.

The supplied PCB revision and firmware example have not been validated as a complete assembled controller. There are no supported production releases yet.
